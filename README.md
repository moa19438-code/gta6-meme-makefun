A GTA 6 meme entry for make.fun's "Post a GTA 6 meme on X" bounty: a skeleton who waited 13 years since GTA V, still holding the controller, while the make.fun ghost floats in with its star coin. Posted from @mohaalherb on X; the post itself is the entry.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` copies `POST.json` (the X post's address) to the output directory, byte for byte. `POST.json` currently holds a placeholder until the meme is posted.
